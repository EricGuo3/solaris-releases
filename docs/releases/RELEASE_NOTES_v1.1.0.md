# Solaris v1.1.0

Solaris v1.1.0 在 v1.0.0 的本地优先项目工作方式上，集中改善了启动可靠性、全局搜索、收件箱处理、Markdown 记录导航与常用界面交互。

## 主要更新

- 提升启动可靠性：同一用户重复打开 Solaris 时会唤醒已有窗口，避免多个实例同时访问工作区。
- 改进全局搜索：提供最近任务、事件记录、项目记录和文档快捷入口，并可一键清除搜索状态。
- 准确定位搜索结果：打开任务或文档结果后会切换到对应页面、选中目标并滚动到可见位置。
- 完善收件箱待确认流程：处理事项后保持当前筛选并聚焦下一项，全部处理完毕后显示明确终态。
- 新增记录大纲：项目记录和事件记录可按一至三级标题显示大纲，能够快速定位对应内容。
- 周期与进度交互：项目手动进度限定为 0—100 的整数，周期设置、收件箱页签、筛选和排序控件保持一致。
- 统一弹层退出：常用弹层支持点击遮罩或按 `Esc` 关闭，未提交内容不会被保存。
- 优化界面反馈：全局搜索间距、收件箱选中状态、记录工具栏和大纲分隔线在浅色与深色主题下更加统一。

## 系统要求

- macOS 15.7 或更高版本
- Apple Silicon（arm64）

安装包已经过 Developer ID 签名和 Apple 公证。下载后可使用同页提供的 SHA-256 文件校验完整性。

> Solaris 是本地优先应用，不要求注册账户，不包含广告、遥测、云同步或自动更新服务。请自行定期把工作区备份到另一块磁盘。
