# Solaris v1.2.5

Solaris v1.2.5 汇总了 v1.1.0 至 v1.2.5 的主要成果，在本地优先的项目工作方式上，进一步完善了启动与检索、收件箱与记录、项目推进、日期时间、成就海报以及备份恢复体验。

## 主要更新

**更可靠的启动与检索**：重复打开 Solaris 优化；全局搜索提供最近内容入口，并能准确定位任务、记录和文档；
**更顺畅的收件箱与记录体验**：待确认事项处理后自动聚焦下一项，项目、事件记录新增标题大纲与快速定位；
**新增成就海报**：可预览本期成就，保存为单页 A4 PDF，并在 Finder 中直接查看本地位置；
**更清晰的项目推进**：项目概览集中展示下一步任务、节点、事件和最近资源，可方便进行项目检查；
**统一的日期与时间规则**：日期输入统一使用自研控件，并依据系统时区和本地日期保持各页面时间一致；
**更安全的本地备份恢复**：成就海报等新功能已纳入备份，恢复机制优化，大备份校验更加节省内存；
**Bug 修复与体验优化**：集中修复优化表单、日期及成就看板、文档中心、归档及浮层的布局、稳定性与性能。

## 系统要求

- macOS 15.7 或更高版本
- Apple Silicon（arm64）

安装包已经过 Developer ID 签名和 Apple 公证。下载后可使用同页提供的 SHA-256 文件校验完整性。

> Solaris 是本地优先应用，不要求注册账户，不包含广告、遥测、云同步或自动更新服务。请自行定期把工作区备份到另一块磁盘。
