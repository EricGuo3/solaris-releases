# Solaris v1.2.5

Solaris v1.2.5 汇总了 v1.1.0 至 v1.2.5 的主要成果，在本地优先的项目工作方式上，进一步完善了启动与检索、收件箱与记录、项目推进、日期时间、成就海报以及备份恢复体验。

## 主要更新

- 提升启动与检索可靠性：重复打开 Solaris 会唤醒已有窗口；全局搜索提供最近任务、事件记录、项目记录和文档入口，并能准确定位目标内容。
- 完善收件箱与记录导航：处理待确认事项后保持当前上下文并聚焦下一项；项目记录和事件记录新增一至三级标题大纲与快速定位。
- 新增成就海报：支持预览本期成果、保存单页 A4 PDF，并可在 Finder 中直接查看保存位置；预览与最终 PDF 使用同一份成果内容。
- 强化项目推进视图：项目概览集中展示下一步任务、检查项目、下一个节点、下一个事件和最近资源；空态可直接进入日期看板创建对应内容。
- 统一日期与时间体验：全软件日期输入复用共享控件，各页面依据 macOS 系统时区和本地日期保持一致，并在时区变化、跨午夜和重新激活后自动刷新。
- 增强本地备份恢复：成就海报纳入工作区备份；旧版本备份会先在隔离区迁移到当前数据结构并完成健康校验，再切换到正式工作区。
- 改进大数据量稳定性：优化周期数据查询、备份校验内存占用和长时间运行资源表现，保持本地数据完整性检查。
- Bug 修复与体验优化：集中修复并优化表单、日期看板、成就看板、文档中心、归档页面、搜索结果及常用浮层的布局、反馈、响应式表现和交互一致性。

## 系统要求

- macOS 15.7 或更高版本
- Apple Silicon（arm64）

安装包已经过 Developer ID 签名和 Apple 公证。下载后可使用同页提供的 SHA-256 文件校验完整性。

> Solaris 是本地优先应用，不要求注册账户，不包含广告、遥测、云同步或自动更新服务。请自行定期把工作区备份到另一块磁盘。
