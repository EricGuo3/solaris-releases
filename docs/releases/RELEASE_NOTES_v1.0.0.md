# Solaris v1.0.0

Solaris v1.0.0 是首个正式 1.0 版本，继续坚持本地优先、一个项目一件当前任务的工作方式，并完善了事件、记录、搜索与大屏体验。

## 主要更新

- 新增事件记录：可在事件详情中创建 Markdown 记录，整理事实、决定与后续事项，在专用页面预览或编辑。
- 重做全局搜索：按 `⌘K` 统一搜索项目、任务、事件、记录、备忘和文档，结果更紧凑，可直接打开目标内容。
- 完善周期事件：项目详情默认按周期系列折叠，按需加载相关发生记录，避免高频事件淹没列表。
- 优化项目详情：事件、里程碑、备忘、记录和文档的日期、排序、密度、悬停与点击反馈更加一致。
- 优化日期看板：重复规则、日期选择、事件编辑与返回定位更清晰。
- 优化UI显示：内容框架适配更宽窗口，减少全屏两侧无效留白。
- 华丽的侧栏：导航区域、底部设置区与原生磨砂效果在浅色、深色及跟随系统主题下保持一致。
- 加强可靠性：补强故障隔离、工作区安全退出、备份菜单与 Markdown 渲染处理。

## 系统要求

- macOS 15.7 或更高版本
- Apple Silicon（arm64）

安装包已经过 Developer ID 签名和 Apple 公证。下载后可使用同页提供的 SHA-256 文件校验完整性。

> Solaris 是本地优先应用，不要求注册账户，不包含广告、遥测、云同步或自动更新服务。请自行定期把工作区备份到另一块磁盘。
