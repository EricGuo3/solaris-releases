# Solaris v1.3.1

Solaris v1.3.1 汇总了 v1.2.5 至 v1.3.1 的主要成果，新增日期涂色标记持久化与归档备忘安全删除恢复，并集中优化了项目详情、Markdown 记录工作台和深色主题体验。

## 主要更新

- **新增日期涂色标记**：可在日期看板的月视图和周视图中使用浅红、浅蓝或双色标记日期，设置会随工作区持久保存并纳入备份恢复；
- **归档备忘支持安全删除与恢复**：已归档备忘可移入“最近删除”，并在保留期内恢复原状态，相关任务与项目关系保持不变；
- **项目记录工作台更顺畅**：优化 Markdown 大纲定位与预览滚动，增加项目记录正文输入空间，并完善工作台边界与主题表现；
- **项目详情信息更聚焦**：优化任务、里程碑、事件、最近资源、重要文档和检查器的展示与操作，让关键信息更容易浏览和定位；
- **Bug 修复与体验优化**：集中修复并优化日期看板、项目详情、当前任务、文档中心和深色主题下的布局、配色与交互体验。

## 系统要求

- macOS 15.7 或更高版本
- Apple Silicon（arm64）

安装包已经过 Developer ID 签名和 Apple 公证。下载后可使用同页提供的 SHA-256 文件校验完整性。

> Solaris 是本地优先应用，不要求注册账户，不包含广告、遥测、云同步或自动更新服务。请自行定期把工作区备份到另一块磁盘。
