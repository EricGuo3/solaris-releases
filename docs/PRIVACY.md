# Solaris 隐私说明

适用版本：Solaris v1.3.1
生效日期：2026 年 8 月 9 日

## 1. 本地优先

Solaris 是本地优先的 macOS 应用。

Solaris v1.3.1 不要求注册账户，不提供云同步服务，也不包含广告、用户行为分析、遥测或自动更新服务。

## 2. 数据收集

Solaris v1.3.1 不会由 Solaris 权利人主动收集或接收用户的项目数据、任务、事件、记录、备忘、文档内容、搜索内容或使用行为。

应用不会自动将工作区内容上传到 Solaris 权利人或其他 Solaris 服务。

## 3. 本地数据

Solaris 的业务数据保存在用户选择的本地工作区中，可能包括：

- 项目、任务、里程碑和日历事件；
- 记录、备忘及文档信息；
- 用户选择复制到工作区的文件；
- 搜索索引、备份和工作区设置；
- 本地诊断记录。

用户负责管理其工作区目录、设备权限和可用备份。

## 4. 本地诊断

Solaris 的诊断记录保存在用户工作区的本地 `logs` 目录中，并按应用规则进行滚动保留。

诊断记录不用于远程遥测。应用不会主动上传这些记录。

诊断记录不应包含备忘或 Markdown 正文、搜索词、文件内容、完整外部文件路径或原始请求标识。

如用户主动向他人提供诊断记录或工作区文件，则该分享行为由用户自行决定和负责。

## 5. 外部文件和备份

当用户选择链接、复制、导出或备份文件时，Solaris 会按照用户操作在本地文件系统中处理相关数据。

用户应在分享、迁移或删除文件前确认其中不包含不希望披露的信息，并自行维护重要数据的可恢复副本。

## 6. GitHub 下载页面

Solaris 安装包通过 GitHub Releases 提供。用户访问 GitHub 或下载安装包时，GitHub 可能依据其自身条款和隐私声明处理访问及下载相关信息。

Solaris 权利人不通过 Solaris 应用获取 GitHub 的用户账户密码或私人仓库内容。

## 7. 隐私问题反馈

如需反馈 Solaris 的隐私问题，可以通过本仓库的 GitHub Issues 联系。

请勿在公开 Issue 中提交工作区、诊断日志、个人信息、公司机密或其他敏感内容。

## 8. 说明更新

如果未来版本增加联网、账户、同步、遥测或其他数据处理能力，本说明将在相关版本发布前更新。
